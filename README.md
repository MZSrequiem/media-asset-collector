# 影视种子与字幕整理工具

这是一个仅使用 Python 标准库的 Windows 图形工具。它只读扫描源目录，不会移动、重命名、删除或改写任何源文件。

## 为什么做这个工具

很多人会把影视文件直接保存在本地硬盘上，但暂时没有条件搭建 NAS，也没有足够的长期存储空间。当视频文件占用大量容量时，可以把体积很小的 `.torrent` 种子文件和外挂字幕单独整理保留，作为未来重新获取同版本资源的线索。在用户自行确认后，这种做法可以为本地视频腾出空间，同时尽量保留已收集资源的恢复线索和字幕。

但种子文件只是下载线索，不是视频备份。做种者可能离线，资源可能失效，未来的下载速度和完成度也无法保证。因此这只是存储空间不足时的缓兵之计，不能代替 NAS、离线硬盘或其他真正的备份方案。本工具不会删除原视频；如果需要释放空间，请先确认种子和字幕已正确提取，再由用户手动决定是否处理原视频。

## 主要功能

- 采用分级规则检查种子与本地视频：优先比较“相对路径 + 精确字节大小”，其次比较“文件名 + 大小”；只靠剧集编号和大小命中的结果会明确标为“疑似匹配”。
- 健康检查界面可筛选异常种子、孤立字幕、没有对应种子的视频，以及重复或疑似重复项。
- 检查字幕与同项目视频的关联；字幕内容相同、种子 Info Hash 相同会被识别为重复项。
- 视频默认只按大小提示“疑似重复”；勾选完整 SHA-256 后，才会确认内容完全相同。
- 根据种子的原始 `info` 数据计算 Info Hash，并导出磁力链接。
- 生成本地视频的路径、大小、修改时间、分辨率/编码文件名线索与种子匹配状态清单。
- 可选计算本地视频完整 SHA-256；这会读取每个视频的全部内容，大型媒体库可能需要很长时间。
- 使用文件大小和修改时间校验扫描缓存，未变化的字幕或视频哈希无需重复计算；缓存可以随时清除。
- 扫描和视频哈希计算可以中途停止。停止后保留部分预览，但必须重新完整扫描后才能复制整理。
- 可选把种子和字幕合并到一个文件夹，或分类整理。
- 源目录始终只读；不移动、不重命名、不删除原文件。

## 使用

1. 从 GitHub Releases 下载 `media-asset-collector-windows-x64.exe` 直接运行；或安装 Python 3.10 以上并双击 `启动工具.bat`。
2. 选择影视资源目录和一个单独的输出目录。
3. 选择是否勾选“种子和字幕放在同一文件夹”、是否使用扫描缓存，以及是否计算视频 SHA-256。
4. 点击“1. 扫描预览”，在“种子与字幕”和“本地视频健康检查”中检查匹配与重复提示；右上方筛选器可只看异常项。
5. 点击“2. 复制整理并生成报告”。

## 输出内容

- 同目录模式：`提取文件/` 中统一保存所有种子和字幕。字幕名会包含原相对路径，避免重名。
- 分类模式：分别保存在 `种子/` 和 `字幕/`，字幕保留项目内层级。
- 种子在两种模式下都优先使用内部 `info.name` 资源名命名。
- `文件清单.csv`：可用 Excel 打开的详细列表。
- `磁力链接.txt`：从有效种子生成的磁力链接清单。
- `视频媒体信息.csv`：本地视频基本信息、可选 SHA-256 与种子匹配状态。分辨率和编码仅从文件名推测，不保证准确。
- `重复项报告.csv`：汇总内容相同的种子/字幕/视频，以及仅按大小推测的疑似重复视频。
- `统计报告.html`：可直接用浏览器打开的统计报告。
- `统计数据.json`：便于其他程序继续处理的数据。
- `错误日志.txt`：仅在有文件复制失败时生成。

工具会自动跳过已生成的历史输出目录，即使它位于资源目录内，也不会被二次提取。

扫描缓存保存在当前 Windows 用户的 `%LOCALAPPDATA%\MediaAssetCollector`，不写入影视资源目录。缓存只保存路径、大小、修改时间和已计算哈希，不保存文件内容；也可以在程序中点击“清除当前目录缓存”。

支持的字幕扩展名：`.srt` `.ass` `.ssa` `.vtt` `.sub` `.idx` `.sup` `.smi`。macOS 生成的 `._` 元数据会自动忽略。

## 命令行可选用法

```powershell
python .\media_asset_collector.py --source "E:\\资源" --preview
python .\media_asset_collector.py --source "E:\\资源" --output "E:\\整理结果"
python .\media_asset_collector.py --source "E:\\资源" --output "E:\\整理结果" --separate
python .\media_asset_collector.py --source "E:\\资源" --output "E:\\整理结果" --hash-videos
python .\media_asset_collector.py --source "E:\\资源" --preview --no-cache
python .\media_asset_collector.py --source "E:\\资源" --preview --clear-cache
```

## 构建 Windows EXE

在 Windows PowerShell 中运行 `build_exe.ps1`。脚本会使用 `requirements-build.txt` 中锁定的 PyInstaller 版本，并把单文件程序生成到 `dist/`。

## 安全说明

本工具仅用于整理用户有权使用的本地文件。扫描期间只读源目录；整理时只向用户指定的输出目录复制文件。
